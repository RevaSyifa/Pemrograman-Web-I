Contoh perintah HTML

HTML menyusun struktur halaman web menggunakan elemen yang ditulis dengan tag. Lihat contoh kode di sebelah kiri dan hasilnya di sebelah kanan.

Teks Format Daftar Tautan & gambar Tabel Formulir Semantik

Tag HTML biasanya memiliki tag pembuka dan penutup, misalnya <p> dan </p>. Beberapa elemen seperti <img> tidak memiliki tag penutup.

1. Judul dan paragraf

Gunakan heading untuk menyusun tingkat judul dan paragraf untuk teks biasa.

Kode HTML
<h1>Judul utama</h1>
<h2>Judul bagian</h2>
<h3>Judul kecil</h3>
<p>Ini adalah sebuah paragraf.</p>
Hasil

Judul utama

Judul bagian

Judul kecil

Ini adalah sebuah paragraf.

2. Format teks dan baris

Tandai penekanan, teks penting, baris baru, atau pemisah topik.

Kode HTML
<p>Teks <strong>penting</strong>.</p>
<p>Teks <em>ditekankan</em>.</p>
<p>Baris pertama<br>baris kedua</p>
<hr>
Hasil

Teks penting.

Teks ditekankan.

Baris pertama
baris kedua

3. Daftar

<ul> membuat daftar berpoin, sedangkan <ol> membuat daftar bernomor.

Kode HTML
<ul>
  <li>Apel</li>
  <li>Jeruk</li>
</ul>
<ol>
  <li>Buka editor</li>
  <li>Tulis HTML</li>
</ol>
HasilBuah
  • Apel
  • Jeruk
Langkah
  1. Buka editor
  2. Tulis HTML

4. Tautan dan gambar

Gunakan atribut href untuk alamat tautan dan src untuk sumber gambar.

Kode HTML
<a href="https://example.com">
  Kunjungi Example
</a>
<img src="gambar.jpg"
  alt="Pemandangan gunung">
Hasil

Kunjungi Example

5. Tabel

Susun data dengan baris, judul kolom, dan sel.

Kode HTML
<table>
  <tr>
    <th>Nama</th>
    <th>Nilai</th>
  </tr>
  <tr>
    <td>Ayu</td>
    <td>90</td>
  </tr>
</table>
Hasil
NamaNilai
Ayu90
Bima85

6. Formulir

Label membantu menjelaskan input yang perlu diisi pengguna.

Kode HTML
<form>
  <label for="nama">Nama</label>
  <input id="nama" name="nama"
    type="text" placeholder="Nama kamu">
  <button type="button">Kirim</button>
</form>
Hasil

7. Elemen semantik dan detail

Elemen semantik menjelaskan peran isi halaman; <details> dapat dibuka dan ditutup.

Kode HTML
<blockquote>
  Belajar sedikit demi sedikit.
</blockquote>
<details>
  <summary>Lihat catatan</summary>
  Isi tambahan ditampilkan di sini.
</details>
Hasil
Belajar sedikit demi sedikit.
Lihat catatan

Gunakan elemen seperti <header>, <main>, dan <footer> untuk memberi struktur halaman yang jelas.
